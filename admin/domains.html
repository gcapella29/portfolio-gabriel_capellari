Conectar na Vercel

1. Salve o domínio aqui
Isso associa o hostname ao project_id no Supabase.
2. Adicione o mesmo domínio na Vercel
Projeto Vercel → Settings → Domains → Add Domain.
3. Configure o DNS
Use exatamente os registros que a Vercel mostrar. Para wildcard, configure o domínio/nameservers conforme a Vercel solicitar.
4. Teste
Quando o DNS propagar, o middleware identifica o hostname e serve o projeto correto sem mostrar site.html?project=....
